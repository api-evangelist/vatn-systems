# Vatn Systems

> Vatn Systems is a Bristol, Rhode Island defense technology company founded in 2023 that designs and
> manufactures low-cost, modular autonomous underwater vehicles (UUVs/AUVs) plus the autonomy,
> navigation and acoustic-processing software that runs on them. It publishes no public API, no
> developer portal, and no machine-readable contract of any kind.

## What Vatn Systems sells

Vehicles (UUVs)
- Skelmir S6 — 6-inch diameter, man-portable, modular, swarm-capable compact AUV: https://www.vatn.com/skelmir-s6-small-auv-drone
- Skelmir S12 — medium-class 12.75-inch platform with extended range and payload capacity: https://www.vatn.com/skelmir-s12-medium-auv-drone

Sensors (hydrophone arrays)
- Eyra 5.1 — rigid-mount hydrophone array optimized for unmanned platforms: https://www.vatn.com/eyra-5-1-multi-hydrophone-array
- Eyra 8.0 — custom-geometry hydrophone array for mission-specific sensing: https://www.vatn.com/eyra-8-0-hydropone-array

Software systems
- INStinct — maritime inertial navigation for GPS-denied operation; MEMS-to-FOG modular sensor architecture, DVL integration, fuses customer-provided aiding sources: https://www.vatn.com/auv-inertial-navigation-system
- PARse — embedded acoustic signal processing (filtering, beamforming, normalization, detection, angle estimation) running on 32/64-bit ARM (proven on Zynq MicroZed and Jetson Nano); included with Eyra arrays and separately licensable for third-party platforms: https://www.vatn.com/parse-acoustic-signal-processing
- FUSE — multi-sensor multi-target tracking engine distributed as a Docker image for x86-64; outputs target state in relative or UTM coordinates: https://www.vatn.com/fuse-data-fusion
- AEsir — TAK-native sensor fusion and common operating picture; ingests heterogeneous detections and tracks: https://www.vatn.com/aesir-maritime-sensor-fusion
- SIGURD: https://www.vatn.com/sigurd
- Mission planning — ATAK plugin (CivTAK, MilTAK, WinTAK) and Fathom, a browser-based mission planner and vehicle configurator: https://www.vatn.com/uuv-mission-planning

## Integration surfaces (all private; none has a published contract)

- TAK / Cursor-on-Target: AEsir is described as TAK-native and Vatn ships an ATAK plugin. No CoT
  message schema or plugin manifest is published.
- FUSE topside protocol: the FUSE page states "Open source protocol for pushing results into custom
  topside applications." No specification, schema or repository for that protocol could be found.
- PARse "configurable ingest": accepts a customer element data format. The format is not documented
  publicly.
- INStinct aiding-source interface: "provides a straightforward interface to integrate other sensors."
  No interface control document is published publicly.
- Fathom: a browser-based configurator that connects to the vehicle. No HTTP API is documented and no
  host for it resolves publicly.
